This repository is forked from UCMEC. An overview of this study and other baseline information can be found [here](https://github.com/gundoganalperen/DIRAL) and [paper](https://arxiv.org/abs/2010.05290).

## Requirements
* Python 3.6
* Tensorflow 1.14
* Numpy 1.19.2
* PyYAML 5.3.1

## Run an experiment
```
bash run.sh
```
* Run the `python main_test.py` command to launch the training.
